<h2>Odin Recipes</h2>
A simple recipes page with HTML and CSS.

<h3>About</h3>
This project is a basic recipes website built using HTML and CSS. It demostrates the fundamental of web <br>development skill such as creating webpages, linking page together, adding images, and organizing<br>content.

<h4>Features</h4>
Homepage with a list of recipes
Individual recipe pages
Recipe images
Ingredients lists
Cooking instructions
Links between pages
Basic CSS styling

<h5>Technologies Used</h5>
HTML5
CSS53
